
# Odin Recipes

Odin Recipes is a basic recipe website built as part of The Odin Project Foundations course.

The website will contain a main page with links to several recipe pages. Each recipe page will include an image, description, ingredients, and cooking steps.

## Skills Demonstrated

By completing this project, I will demonstrate my ability to:

- Create and structure HTML documents
- Use HTML headings, paragraphs, links, images, and lists
- Create links between multiple HTML pages
- Organize files and directories
- Use relative paths
- Use Git for version control
- Create meaningful Git commits
- Push a project to GitHub
